## 한 줄 소개

## 핵심 목표 (요약)

- **오프라인 보상**: UTC 타임스탬프, 앱 종료~재실행 경과 시간 기반 골드 (최대 6시간), AdMob으로 2배 등.
- **가챠**: 가우스(정규분포) 기반 확률, 부위별 DropTable, **천장(Pity)**.
- **데이터**: Firebase 저장 + Addressables로 원격 에셋, 스토어 재심사 없이 패치 지향.
- **빌드**: Jenkins + GitHub Webhook으로 Push 시 AAB 빌드 자동화.
- **전투**: FSM 자동 전투, 8비트 Flags Enum 속성, `IDamageable` 표준화.
- **최종 목표**: Google Play 정식 출시.

## 구현·기획 컨텐츠 요약

1. **Addressables + Firebase Hosting** — UniTask 비동기, 패치 크기 0이면 즉시 씬 전환, 다운로드 진행률 UI.
2. **Jenkins CI/CD** — `MenuItem` / `BuildPipeline`, Unity CLI `BuildAutomator.Build`, 스테이지별 로그로 실패 지점 추적.
3. **Firebase Analytics** — 강화·챕터·광고 등 이벤트 로깅, 밸런싱·이탈 분석.
4. **모바일 UI** — SafeArea, CanvasScaler(기준 1080×2340), New Input System(Touch 등).
5. **가챠** — 진행도에 따라 분포 중심 이동, 커스텀 에디터에서 weights 시각화.
6. **오프라인 보상** — `OnApplicationPause`/`Quit`에 UTC 저장, Unix 초 단위 경과(상한 21,600초).
7. **속성 전투** — `[Flags]` Enum + StateMachineBehaviour, 비트 연산, 이펙트 풀링.
8. **인벤토리 MVP** — Model(SO) / Presenter / View 분리, 인터페이스로 확장.
9. **DTO + Firebase** — JSON 직렬화 자동 저장(`quitting`/`pause`), 변조 완화.
10. **FSM 전투** — Physics2D 탐지, DOTween 연출, 몬스터 풀링·리스폰.
11. **2D 패럴랙스** — Material Offset + Repeat, 전투 중 정지 후 재개.
