SoloSoft(이하 "개발자")는 모바일 게임 "솔로히어로"(이하 "게임")를 이용하는 분의 개인정보를 소중히 다루며, 관련 법령을 지킵니다. 게임은 이름, 전화번호, 이메일 같은 개인정보를 직접 입력받지 않습니다.

2. 보관 기간과 파기

  • 게임 진행 데이터: 이용자가 삭제하거나 게임 서비스가 끝날 때까지 보관합니다.
  • 기기 이전 코드의 진행 사본: 발급 후 24시간이 지나면 읽을 수 없고, 새 기기에서 쓰거나 이용자가 데이터를 삭제하면 지웁니다.
  • 이용·오류 기록: Firebase Analytics 설정에 따른 기간(최대 14개월)이 지나면 자동 삭제됩니다.
  • 광고 관련 정보: Google의 정책에 따라 처리됩니다.
  • 앱을 삭제하면 기기에 저장된 백업도 함께 삭제됩니다.

3. 제3자 제공과 국외 이전

개발자는 수집한 정보를 판매하거나 제3자에게 제공하지 않습니다. 위 표의 Google 서비스(Firebase, AdMob)가 서비스 제공을 위해 정보를 처리하며, 이 과정에서 정보가 대한민국 밖(미국 등 Google 데이터센터 소재국)으로 전송·저장될 수 있습니다. 전송은 앱 사용 중 네트워크를 통해 이루어집니다.

  • Google 개인정보처리방침: https://policies.google.com/privacy
  • Google이 파트너 앱의 정보를 사용하는 방식: https://policies.google.com/technologies/partner-sites

4. 이용자의 권리

  • 데이터 삭제(앱 안): 설정 → 계정 → 모든 데이터 삭제를 누르면 서버의 진행 데이터, 익명 계정, 발급한 기기 이전 코드, 기기에 저장된 데이터를 지우고 분석 식별자를 초기화한 뒤 처음부터 시작합니다. 되돌릴 수 없습니다.
  • 데이터 삭제(이메일): 앱을 이미 지웠다면 문의 이메일로 요청해 주세요. 설정 → 계정에 보이는 계정 ID를 알려 주시면 빠르게 처리하고, 모르시면 사용 기기와 대략의 설치 시기로 확인합니다.
  • 기기 이전: 설정 → 계정에서 코드를 발급해 새 기기의 같은 화면에 입력하면 진행이 옮겨집니다.
  • 광고 동의(유럽 경제 지역·영국·스위스): 처음 실행할 때 동의 화면이 나오며, 설정 → 계정 → 개인정보 옵션에서 언제든 바꿀 수 있습니다.
  • 광고 개인화 거부: 기기 설정 → Google → 광고에서 광고 ID를 재설정하거나 삭제할 수 있습니다.
