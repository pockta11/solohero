# 콘텐츠 등급 설문(IARC) 답변 (E9-14, E9-15, E9-16)

Play Console → 앱 콘텐츠 → 콘텐츠 등급. 한국은 IARC 결과가 게임물관리위원회 등급으로 인정된다(구글 플레이는 자체등급분류사업자).

## 확률 공시 (E9-15)

- 법적 의무(게임산업법 확률형 아이템 정보 공개, 2024-03-22 시행)는 **유상 구매 가능한** 확률형 아이템 대상이다. 솔로히어로는 인앱 결제가 없어 의무 대상은 아니다.
- 그래도 GDD 원칙대로 게임 안(소환 탭)에 등급별 확률 4행과 천장·리셋 규칙을 상시 표시하고, 스토어 설명에도 같은 확률을 적는다.
- **인앱 결제로 젬을 팔기 시작하면** 의무 대상이 된다: 게임 화면·스토어·홈페이지 3곳 공시, 확률 검증(E5-14 GachaVerifier 10만 회 실측) 기록 보관이 필요하다.

## 광고 정책 (E9-16)

- 보상형 광고만 쓰고, 버튼에 "광고:" 라벨과 보상 내용을 표시한다 (`ad.gem_button`, `ad.booster_button`, `offline.double`).
- 광고를 보지 않아도 진행 가능 (V-1 무광고 시뮬레이션, E9-21).
- 테스트 중 본인 광고 클릭 금지. 개발 빌드는 테스트 광고 ID를 쓴다 (`BuildConfig`).
- 타깃 연령 13세 이상으로 설정 → 가족 정책(인증 광고 SDK 요구) 대상 아님.
