# 드로우콜 원인 분석 (2026-10-08)

출시 게이트 E9-19 "전투 드로우콜 120 이하"가 09-28 측정(전투 100~116) 이후 넘었다(10-08 평소 117~150, 순간 240~300). 원인을 기기에서 직접 쪼개 쟀다.

## 방법

- 개발 빌드 전용 `Game/Diagnostics/DrawCallProbe.cs`. 기기의 `files/dc_probe.txt`가 있을 때만 동작하고 릴리스 빌드에서는 컴파일되지 않는다.
- 전투가 시작되고 12초 뒤, 화면 요소를 묶음별로 잠깐 숨긴다(월드 렌더러 끄기 / UI 그래픽 cull, 로직은 그대로). 숨기기 전후 24프레임의 "Draw Calls Count" 중앙값 차이를 그 묶음의 비용으로 본다. 큰 묶음은 자식 단위로 다시 쪼갠다(93묶음). 지금 보이는 렌더러와 UI 그래픽도 재질·텍스처별로 센다.
- 에뮬레이터 `solohero_fast`, 8-9 파밍, 화염술사 Lv 75, 캐릭터 탭이 열린 평소 전투 화면.
- 전투 장면이 계속 바뀌어 한 번의 측정에 ±10 잡음이 있다. 그래프 몇 개짜리 작은 묶음은 믿지 않고 큰 묶음만 본다.

## 원인

1. **UI 스프라이트 아틀라스가 없다.** 패커는 Sprite Atlas V2로 켜져 있지만(`m_SpritePackerMode: 5`) `.spriteatlas`가 하나도 없다. 그래서 UI 이미지마다 자기 텍스처를 쓰고(스킨 9-슬라이스·아이콘 67장), uGUI는 텍스처가 바뀔 때마다 묶음을 끊는다. 사이사이 글자(폰트 텍스처)까지 끼면 거의 그래픽 2개마다 드로우콜 하나가 된다.
2. 09-28 이후 늘어난 몫은 전부 UI 요소다. 스킨 v3 아이콘(D-108), 가이드 퀘스트·전투력(D-111·D-127), 능력치 6줄 카드·돌파석(D-142·D-143), 오른쪽 메뉴 9칸(D-132) 등 새 요소마다 고유 텍스처가 붙었다.
3. 월드는 문제가 아니다. 스킬 연출(D-146)도 10초 구간 최고를 +20 정도 올릴 뿐이다.

순간 240~300이 어떤 장면인지는 아직 못 잡았다. 감시 모드(파일 내용 `spikes`: 200을 넘는 프레임마다 떠 있는 UI 블록 기록)를 넣은 빌드가 PC 메모리 부족으로 중단됐다.

## 처방 (제안)

- **UI 아틀라스 2장 (Sprite Atlas V2, 2048×2048):**
  - ① UI 스킨: `Art/UI/Hd` 루트 70장 + `Hd/Icons` 43장 + `Art/UI` 루트 47장 + `Icons` 22장, 약 196만 px
  - ② 아이템 아이콘: `Hd/Equipment` 70장 + `Hd/Skills` 67장, 약 225만 px
  - 설정: 회전 끔, 타이트 패킹 끔(9-슬라이스), 패딩 4, 바이리니어(지금 UI 텍스처와 같음)
  - 이미지끼리 텍스처를 공유하면 uGUI가 겹치지 않는 이미지를 한 묶음으로 합친다. 예상 UI 약 115 → 30~45, 프레임 약 130 → 45~60.
- 아틀라스는 ArtBuilder가 만들게 해 재생성에도 유지한다. 원래 텍스처는 그대로 두고 아틀라스는 빌드 때 패킹된다.
- 그다음 감시 모드로 순간 급등 장면을 잡아 필요하면 개별 처리한다.

**첫 분석의 정정.** 위 결과 표의 "월드 6~10"은 측정 방식 탓에 낮게 나온 값이다. 측정기가 렌더러를 `enabled = false`로 숨겼는데 전투 화면(`CombatWorldView`)이 적·그림자·체력바·코인 렌더러를 매 프레임 다시 켜서, 숨긴 것이 바로 되살아났다. `forceRenderingOff`로 고쳐 다시 재니 월드 스프라이트는 **동적 배칭이 꺼져 있어 하나에 드로우콜 하나**였다. 순간 급등(동적 배칭 전 123)은 궁극기로 무리를 쓰러뜨리는 순간이었다: 코인 24 + 효과 클립 17·빛 번짐 9 + 그림자 9 + 쓰러지는 적 8 + 컷인 띠. 동적 배칭을 켜자 같은 재질·텍스처(같은 아틀라스)의 스프라이트가 묶여 월드 비용이 12~19(보이는 렌더러 21~35)가 됐다.

**남은 것.** 5분에 1~3번, 큰 스킬이 무리를 쓸어 코인·효과·숫자가 한꺼번에 뜨는 한 프레임이 108~124까지 오른다. 평소와 상위 10 %는 예산의 절반 수준이라 출시 게이트는 통과로 본다. 캐릭터는 재질 속성 블록(피격 번쩍임, D-096)을 써서 묶이지 않는다(약 10).

**잡음 메모.** 장시간 세션에서 에뮬레이터 FPS가 점점 떨어진다(60 → 3). 드로우콜 수 자체는 FPS와 무관하지만, 10초 창의 최고값은 프레임이 많을수록 높게 잡히므로 비교는 같은 FPS에서 한다(콜드 재시작 후).
