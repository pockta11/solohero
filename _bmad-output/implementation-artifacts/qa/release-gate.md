## 2시간 방치 재실행 (E9-10, 2026-10-08)

릴리스 설정 QA 빌드(x86_64, 광고 SDK 끔), AVD `solohero_fast`(host GPU), `pwsh tools/qa/Qa.ps1 idle -Minutes 120`. 결과는 `Builds/qa/idle-120.csv`와 아래 기록.

120분 동안 앱 유지(크래시 0), PSS 318 MB → 327 MB(**+2.8%**, 목표 +20% 이내·400 MB 이하), 최고 스테이지 82 → 89, 레벨 60 → 77, Unity 오류 로그 0. 이전 회차(2026-09-28)에 100분에서 에뮬레이터 `system_server`가 죽었던 문제는 host GPU AVD에서 재현되지 않음. 실기기 2시간은 여전히 권장.
