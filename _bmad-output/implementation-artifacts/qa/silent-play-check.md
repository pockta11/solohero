# 무음 플레이 검증 (E8-14)

GDD: "무음 플레이가 기본 가정이다 — 오디오 없이도 전투 정보가 전부 시각으로 전달되어야 한다."
설정에서 배경음·효과음을 모두 끄고 확인한 항목. 효과음 18종이 전하는 정보마다 대응하는 화면 표시가 있다.

| 효과음 | 전하는 정보 | 무음일 때 화면 표시 | 결과 |
|---|---|---|---|
| hit / crit | 타격, 크리티컬 | 데미지 숫자(크리티컬은 노란색·확대·포물선), 적 피격 플래시, 타격 이펙트 | ✅ |
| hero_hurt | 히어로 피격 | 히어로 붉은 플래시 + 피격 애니메이션 | ✅ |
| enemy_death | 처치 | 사망 애니메이션/연기, 킬 카운터 `N / 8` | ✅ |
| boss_intro | 보스 등장 | 암전 + 보스 이름 배너 + 카메라 셰이크, 30초 타이머 표시 | ✅ |
| skill1~3 | 스킬 발동 | 스킬 이펙트(폭발·회오리·링), 버튼 쿨다운 숫자 | ✅ |
| gold | 스테이지 보상 | 골드 카운트업 + 라벨 튀어오름 | ✅ |
| level_up | 레벨업 | 레벨업 링 + "레벨 N 달성!" 토스트 | ✅ |
| upgrade | 강화 성공 | 행 펀치, 레벨·비용 갱신 | ✅ |
| card_flip / grade_epic / grade_legendary | 가챠 결과 | 카드 뒤집기, 등급 색·이름, 영웅 이상 파티클·흔들림 | ✅ |
| tap / panel_open / panel_close | 조작 반응 | 버튼 눌림, 탭 강조색, 패널 표시 | ✅ |
| toast | 알림 | 토스트 박스 1.5초 | ✅ |

이펙트 축소 모드에서도 데미지 숫자·피격 플래시·스킬/레벨업 이펙트·토스트는 유지된다(D-071) — 무음 + 이펙트 축소 조합에서도 정보 손실 없음.
