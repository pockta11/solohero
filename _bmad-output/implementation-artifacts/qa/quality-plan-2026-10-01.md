# 게임 품질 점검과 개선 계획 (2026-10-01)

범위: 게임 안쪽만 — 부드러움(FPS·움직임), 전투 손맛, 캐릭터·배경·UI 마감, 스킬, 성장 콘텐츠. 콘솔·스토어는 `launch-plan-2026-10-01.md`(나중).
근거: 코드·설정 점검 + 에뮬레이터 실행 화면(5-9 스테이지 연속 캡처, `Builds/seq/`).

## 0. 한 줄 진단

시스템(성장·가챠·스킬·특성·저장)은 갖춰졌지만 **화면이 정적이고 끊겨 보인다.** 원인 셋:
① 화면 전체가 270×480 픽셀 단위로 계단식 이동,
② 캐릭터 애니메이션이 10 fps·6~8장,
③ 맞아도 반응이 없는 전투(정지·넉백·흡수 연출 없음).
여기에 배경 톤 불일치와 겹치는 숫자·HP바가 겹쳐 "저예산" 인상을 준다.

## 1. 부드러움 (FPS·움직임) — 가장 먼저

| # | 문제 | 근거 | 해결 |
|---|---|---|---|
| S-1 | **화면 전체가 4px씩 계단 이동** | Pixel Perfect `m_UpscaleRT: 1`, 기준 270×480 → 모든 것이 화면 4px 단위로만 움직인다. 이동 2 u/s = 64 art px/s라 60 fps에서 프레임당 1.07px → 1px·1px·2px 불규칙 떨림. 패럴랙스 레이어(배속 <1)는 몇 프레임 멈췄다 튀어 더 심함 | 업스케일 RT를 끄고 1080×1920으로 직접 렌더(스프라이트는 4배 정수 스케일 유지, 포인트 필터). 카메라·패럴랙스는 서브픽셀로 이동. 대안: RT 2배(540×960) |
| S-2 | **캐릭터 애니가 뚝뚝 끊김** | `CharacterArt.fps = 10`, 클립 6~8장(대기 0.6초 주기 6장) | 3D 파이프라인으로 프레임 2배(대기 12, 공격 10~12, 달리기 12)·재생 16~20 fps. 렌더 비용은 0(사전 생성) |
| S-3 | **적이 제자리에 서 있음** | 적 이동 로직 없음(`HeroBrain`만 이동), 적은 `run` 클립 없음 | 웨이브가 오른쪽 화면 밖에서 달려 들어오는 연출(뷰 전용, Core 판정 불변) + 적 `run` 클립 추가 |
| S-4 | 실기기 FPS를 모름 | 에뮬레이터는 소프트웨어 GPU라 측정 불가, FPS 표시 없음 | 개발 빌드 전용 FPS·프레임타임 오버레이(`#if DEVELOPMENT_BUILD`) |
| S-5 | 불필요한 HDR | `UniversalRP.asset m_SupportsHDR: 1` — 2D 픽셀에 불필요, 모바일 대역폭 낭비 | HDR 끔. 60 fps 기본·30 fps 옵션·Swappy는 이미 켜져 있어 유지 |

## 2. 전투 손맛 (game feel)

| # | 문제 | 해결 (장르 표준) |
|---|---|---|
| F-1 | 타격 정지 없음 | 크리티컬·스킬·처치 시 40~70 ms 히트스톱(뷰 시간만, Core 틱은 그대로) |
| F-2 | 넉백·밀림 없음 | 맞은 적이 0.1~0.2u 밀렸다 돌아오는 뷰 오프셋, 처치 시 뒤로 튕겨 날아감 |
| F-3 | 피격 플래시가 두 가지(붉은 틴트 + 시트에 박힌 전신 흰 프레임)라 번쩍임이 거칠다 | 시트의 흰 프레임 제거, 흰색 오버레이 셰이더 1종으로 통일(60~80 ms) |
| F-4 | 평타(섬광 베기) 이펙트가 가는 파란 호 하나 | 굵은 참격 + 맞은 자리 스파크 + 짧은 셰이크로 강화 |
| F-5 | 처치 보상 연출 없음 | 코인·경험치 구슬이 튀었다가 HUD로 빨려 들어가는 연출(풀링), 골드 카운트업과 연결 |
| F-6 | 데미지 숫자가 겹쳐 읽히지 않음 | 같은 대상 연속 타격은 위로 쌓기, 크리티컬 크게·노랑, 스킬은 색 구분, 수명 단축, 외곽선 강화 |
| F-7 | 적 HP바가 서로 겹침 | 레인별 높이 보정, 바 축소, 마지막으로 맞은 적만 표시 |
| F-8 | 4마리가 한 덩어리로 뭉침 | 레인·간격 재배치, 웨이브 등장 시 시간차 |

## 3. 캐릭터·배경·UI 마감

| A-4 | 캐릭터 잔여 이슈: 버섯 갓이 얼굴을 가림, 그림자 마법사 눈 뭉개짐, 레인저 시트 미사용 | `chibi3d.py` 조정 |
| A-5 | 스킬바 쿨다운 숫자가 아이콘을 가림 | 원형 쿨다운 채움 + 작은 숫자, 준비 완료 시 반짝임 |
| A-6 | 강화가 1회 탭뿐 | 꾹 누르면 연속 강화(가속), ×1/×10/MAX 토글 — 장르 표준 |
| A-7 | 하단 패널 정보 과밀·밋밋 | 스탯 요약 축소, 강화 행에 비용 부족·가능 상태 강조, 레벨업 시 행 펀치 |
| A-8 | 상단 스킬명 팝업이 HUD와 겹침, 좌측 광고 버튼 라벨이 작음 | 위치·크기 정리 |
| A-9 | 앱 아이콘이 이전 아트(왕관 쓴 왕) | 3D 기사로 재제작 |

## 6. 진행 순서

| 단계 | 기간 | 항목 | 끝 조건 |
|---|---|---|---|
| **1. 부드러움 + 손맛** | 2~3일 | S-1~S-5, F-1~F-8 | 연속 캡처·영상에서 떨림·뭉침·겹침 없음, 개발 빌드 FPS 표시 |
